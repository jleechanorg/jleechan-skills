# Headless PR-owner nudger skill and agy owner support

- **Outcome:** Package the headless PR-owner nudger as `.claude/skills/pr-owner-nudger/SKILL.md`, document `/pr --nudge` and `/pr --nudge --stop` in `.claude/skills/pr-workflow-manager/SKILL.md`, support `agy` as a bootstrapped and resumed managed PR owner (`scripts/pr_nudger_round.py`, `scripts/pr_nudger_routes.py`, `scripts/pr_owner_nudger.py`), and let `retry-now --kick` start the first tick on a fresh `state_dir` without creating `receipts.sqlite3`.
- **Non-goals:** No new background daemon or controller; no automatic enabling of dispatch (`enabled: true`) or merging (both stay operator-only); no changes to existing script paths.
- **Acceptance:**
  1. `.claude/skills/pr-owner-nudger/SKILL.md` passes frontmatter, link, and zero-PII portability checks and covers scheduler install (`launchd` `ProcessType` `Interactive`, `systemd` timer), `docs/pr-owner-nudger.md` pointer, round runbook, and operator-only gates.
  2. `.claude/skills/pr-workflow-manager/SKILL.md` documents `/pr --nudge <PR>` and `/pr --nudge --stop <PR>`.
  3. `pr_nudger_round.py enroll --cli agy` writes an `agy` enrollment and deadline wrapper; `start_agy_bootstrap` runs `-p ... --output-format stream-json --model <model> --dangerously-skip-permissions`, `inspect_agy_bootstrap` binds the `conversation_id` from `{"event":"result"}` after verifying the ack and persisted `agy` transcript/`conversation_summaries.db` workspace binding, and `_resume` wakes with `--conversation <id> -p`.
  4. `pr_nudger_round.py retry-now --kick` kicks the scheduler on a fresh `state_dir` without creating `receipts.sqlite3`.
- **User story:** An operator or `/pr --nudge` caller can install, enroll, kick, verify, and retire headless Codex or `agy` PR owners using one portable skill and command flow.
- **Proof plan:** Run `python3 -m pytest -q tests/test_pr_owner_nudger*.py tests/test_pr_nudger*.py`, portability and skill-structure checks (`test_skill_export_no_personal_paths.py`, `test_skill_personal_identifiers.py`, `test_shared_skills.py`, `skill_portability_scan.py`), verify `_session`/`_terminal_state`/`_accepted` against a real local `agy` print-mode session, and obtain two independent full-scope reviews at the candidate head.
- **Mock exemption:** Unit tests isolate GitHub API, scheduler kickstart, and subprocess spawns with disposable directories and fixture executables, supplemented by live `agy -p --output-format stream-json` inspection on disk.
- **Risk:** Accepting a bootstrap or wake without verifying `agy` workspace ownership or idle status could steer an unrelated conversation or double-drive a running session. Fail closed via `conversation_summaries.db` workspace and idle checks, `_writers`, and `_managed_claim`.
