# Retired Slack scraping reference

Historical Slack scraping and API recipes in this file are retired. Use the configured native Slack connector only for operations permitted by its existing scopes; if a method or authorization is unavailable, stop and report the blocker. For browser access, follow `~/.claude/skills/browser-control/SKILL.md` and use only an already authorized, isolated agent-owned context. Never use personal browser state or cookies to bypass Slack authorization.

Virtualized lists may render only the current viewport. A single page-text capture may therefore omit rows; scroll and inspect incrementally, and confirm completion against any total the authorized UI exposes.
