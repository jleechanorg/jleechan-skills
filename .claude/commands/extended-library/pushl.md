# /pushl

`/pushl` is a retired legacy alias. This package does not include a push-lite
implementation, so do not run an unbundled legacy launcher for it.

To push, run `/review` on the changes, push the branch (`git push -u origin HEAD`), and create or update the PR with `gh pr create` / `gh pr edit`.
