# PR Description Format

The shared PR-description structure and ordering are owned by `~/.codex/AGENTS.md` § PR descriptions
(canonical owner). Read and follow that section; this compatibility skill defines no competing section list or
universal content requirements.

Before editing a PR description, inspect the target repository's `AGENTS.md`/`CLAUDE.md` and
`.github/pull_request_template.md`. Preserve repository-specific design-document links, issue/bead fields,
CI markers, evidence records, and scope checks where the local contract requires them. Do not infer an opt-out
or remove a local requirement from the shared pointer.
