# /prw — PR workflow alias

Read and follow [pr-lifecycle](../pr-lifecycle/SKILL.md) for the complete canonical PR workflow: draft-first creation, the six stages, evidence, proportional exceptions, review route, readiness and separate merge authority. This alias defines no independent rules and takes the user's arguments as data.

[PR Workflow Manager](../pr-workflow-manager/SKILL.md) is the discovery and command entry point; [draft-first-pr](../draft-first-pr/SKILL.md) is the legacy alias. If pr-lifecycle is unavailable, report the missing dependency rather than reconstructing stale rules.
