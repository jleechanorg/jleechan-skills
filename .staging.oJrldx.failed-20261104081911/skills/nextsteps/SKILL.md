# Nextsteps

Read the [timeline contract](../parallelize-to-ceiling/references/timeline-milestones.md). Default mode is a lean project tracker/roadmap handoff; --full requests additional explicitly supported memory/issue destinations, not permission to copy hidden or sensitive data.

Reuse completed context gathering. Refresh relevant PR/issue state and exact revisions. Prefer updating an existing suitable handoff over creating competing documents. Identify completed work, open blockers, dependencies, owners, acceptance criteria and a next-action queue runnable without reading chat.

Write the requested handoff in the repository's established location with a title, table of contents, executive summary, context, tracker index, work queue, timeline/parallel lanes, PR state and learnings/roadmap references. Mark inapplicable sections rather than inventing identifiers. Distinguish estimated windows from observed completion and do not start stopped work or future monitoring merely by writing a plan.

Update only authorized existing tracker/roadmap destinations. In --full mode, explicitly report each requested additional sink as completed, unavailable or outside current access; never copy credentials or raw memory. Report chosen mode, artifact path, actual writes and remaining gates. External messages/issues and new schedules require applicable current authority.
